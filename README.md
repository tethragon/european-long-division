# Κάθετη Διαίρεση (Ευρωπαϊκή Μέθοδος) · Math Division App

Διαδραστική εκπαιδευτική εφαρμογή για την εκμάθηση και εξάσκηση της **Κάθετης Διαίρεσης** με την **Ευρωπαϊκή Μέθοδο** (σύστημα που διδάσκεται στα ελληνικά σχολεία, Δ' - ΣΤ' Δημοτικού).

## 🌟 Χαρακτηριστικά (Features)

- **Ευρωπαϊκός Πίνακας Διαίρεσης:** Αυθεντικό layout με τον διαιρέτη δεξιά και το πηλίκο από κάτω.
- **Υποστήριξη Όλων των Ειδών:**
  - Ακέραιοι αριθμοί (τέλειες & ατελείς διαιρέσεις).
  - Ενδιάμεσο μηδέν στο πηλίκο (π.χ. $618 : 6$).
  - Συνέχιση διαίρεσης σε δεκαδικό πηλίκο με κατέβασμα μηδενικού.
  - Δεκαδικός διαιρετέος με ακέραιο διαιρέτη.
  - Δεκαδικός διαιρετέος με δεκαδικό διαιρέτη (διαδραστική μετατόπιση υποδιαστολής $\times 10, \times 100$).
- **Πλήρης Πλοήγηση Πληκτρολογίου:** Auto-tabbing, βελάκια $\leftarrow/\rightarrow$, και Enter για άμεση επικύρωση και κατέβασμα ψηφίου.
- **Game Mode με Σκορ % & Ranks:**
  - 🟢 **Padawan:** Ακέραιες διαιρέσεις (Δ' - Ε' Δημοτικού).
  - 🔵 **Master:** Με δεκαδικά (Ε' - ΣΤ' Δημοτικού).
  - 🟣 **Grand Master:** Όλες οι περιπτώσεις (ΣΤ' Δημοτικού).
  - 🟡 **Sentinel:** Εστιασμένη εξάσκηση στην τρέχουσα κατηγορία.
  - Μετάλλια, σερί (Streak) και τελική απονομή με κομφετί!
- **Πρόχειρο Προπαίδειας & Παιδαγωγικός Οδηγός:** Υποδείξεις βήμα-βήμα και βοήθεια.

## 🚀 Τοπική Εκτέλεση (Local Development)

```bash
# Εγκατάσταση εξαρτήσεων
npm install

# Εκκίνηση dev server
npm run dev
```

Η εφαρμογή ανοίγει στο `http://localhost:3000`.

## 📦 Build για Παραγωγή (Production Build)

```bash
npm run build
```

Ο φάκελος εξόδου είναι ο `dist/`.

## ☁️ Deployment στο Cloudflare Pages

1. **Framework preset:** `Vite`
2. **Build command:** `npm run build`
3. **Build output directory:** `dist`
